# Actual unexposed archive bootstrap store (implementation design)

This is the first physical consuming slice of the archive-host vertical. It is not implemented
yet. Its output is a durably retained **unexposed original source**, not an active Server, Current,
native creation success, message acceptance or production Chat V2. The normal app remains off.
The first full vertical still needs actual Create/accept/lookup/read and cold Current restoration.

The current `FounderArchivePreparation` already owns the genuine original founder, exact private
S0 and original encrypted Genesis3/manifest pages. The App must construct it inside a private
Store-owned creator: no public generic `(Server, archive, labels)` adoption/saver is acceptable.
Actual creation and physical-mount capture occur inside that factory before any source can escape.

## Scope before the first source save

Do not call the old `PrivateManagedServer::reserve_scope` and then hope to persist a source. Its
Initializing write can survive a crash while the founder/device/Fresh proof disappears.

Add a private **original RAM scope plan**, owned by the real creator and registered weakly under
the Store admission serializer. It captures the original mount, actual newly founded group/full
signer/attempt, exact expected VACANT table basis and next nonce/revision. It is negative-only:
no table row, Current, publication or storage permit is created by the plan. Its real revoking
owner observes both original mount and creator cancellation; a copied label cannot adopt it.

While this plan is live, every old admission issuance for that SAME key must refuse before RNG,
old-owner revocation or a row write. It cannot replace the plan by sampling its own nonce. Plan
lookup/removal and final original checks use the same admission mutex; the registry holds a weak
owner so dropping an unexposed creator does not keep it alive. Unrelated groups are unaffected.
Canonical head reservation must use the same group/full-signer exclusion as the old writer,
not a disjoint V2 map. Any existing scope, v1/v2 pin, head or reserved source refuses founding.
The guard is checked inside old `prepare_chat_admission` BEFORE BOTH the privately issued retry/
dirty-flush branch and the new pre-RNG branch. Checking only initial capture misses an older
issued operation that retries after a V2 plan appears. Old source-absent and numeric paths need
the same actual target classification before their first mutation.

Before staging the local private scope, durably save the typed small original FoundingIntent
under the actual declared archive namespace. It records the exact planned lineage and original
Fresh attempt, not a fabricated serialized Fresh token. This is independent durable lineage for
private staging, not a Current row. Attach the SAME RAM plan as the actual reservation, stage
that exact private scope, then prepare/freeze the actual founder, cached S0 and genesis package.
The later scope-table installation must preserve this exact owner identity/nonce; old generic
issuance cannot mint a second one. That installation is outside this first unexposed slice.

The bootstrap source is complete BEFORE any Initializing row is installed. Therefore a failed
bootstrap cannot leave a scope row pretending to be open. Unknown/partial intent/source files
remain negatively reserved and preserved; they cannot authorize another creator or a restore.
The new V2 unexposed-negative adapter is still required for later failures after row installation;
the existing exact-v4 source-absent/S1 recovery remains unchanged.

Split creator lifetime from write debt. The creator alone owns its revoking plan sender and
actual Server/transport. Before the first fallible source I/O, Store registers the complete exact
SERIALIZED encrypted candidate/pages, expected parent/context, held file identities and original
fee in a per-target debt cell. That cell retains only inert identity and ORIGINAL negative
observers, not the creator sender, Server, transport or Store/key/session cycle. Caller Drop
irreversibly cancels positive work, while the same exact bytes remain reserved for bounded
offline/negative repair. Dead weak plan does NOT mean vacant when debt or a persisted intent may
exist. A replacement creator cannot overtake it. Core live-source getters are not a repair API:
the debt already owns the encoded bytes before their original source becomes unavailable.

## Actual configured namespace and old-path exclusion

Use a concrete physical-open policy and supported ARCHIVE ID2/version1 descriptor; no caller-
implemented handler trait, `supported=true` callback or native IPC policy is allowed. Default
Empty and Pending-only openers continue refusing ID2. A concrete combined opener may support
JOIN1+ARCHIVE2 only after both actual inspectors exist. Preserve the exact JOIN payload on
declaration; new messages never rewrite that shared catalog.

The <=4KiB immutable descriptor binds original vault domain, closed layout version and fixed
metadata destinations. Its actual file/root barriers precede dependent source files. Namespace
activation and its orphan check are part of the pre-cleaner constructor. Both current AND stage
catalog sources authenticate and classify completely before any old cleanup or source fallback.

Reserved fixed names are `chat-owner-v2` and `chat-critical-namespaces.archive.seed`. Until the
actual inspector/transaction below exists, both default and Pending-only readers refuse any
presence of either, including a nonregular object or dangling link. That negative guard is
implemented; its two new constructor regressions are authored UNRUN. It enables no archive.

The namespace declaration itself needs exact cold recovery. Persist the original declaration
seed and grant, then write/sync the COMPLETE stage adding ID2 under the exact old-current parent.
Only then create/sync the closed empty root; only after that root barrier promote stage to current
and sync the parent. No dependent source is written before this transaction completes. A complete
known stage/seed over its actual old current may finish the SAME first root creation. An already-
current ID2 declaration with a missing root must NEVER recreate it as empty: the archive is
unavailable/unknown. A root without ID2 in any recognized complete current/stage/seed is an orphan,
not an adoptable empty archive. The first seed's own partial failure cannot authorize cold repair.
The eventual known handler must preserve independently proved other work when only the archive
is unavailable, while unknown critical catalog/layout still prevents old cleaners.

The first inspector supports only the explicitly unexposed bootstrap state. It must recognize
and refuse a later Current/unknown state, not claim general archive/owner support or interpret
it as empty. Adding Current requires its actual SDK/source/head/scope/fee consumer, with a strict
state/schema transition and matching older-reader refusal. No unsupported placeholder is accepted.

Distinguish global format classification from per-target source completeness. Unknown critical
catalog/descriptor/layout cannot run old cleaners. Within the supported layout, malformed/partial
fixed source records for A reserve A negatively and remain intact; they do not make the whole
Store unavailable or prevent independently proved B reopening and doing control work. The fixed
per-target source directory/key/slot inventory must represent Present/Incomplete/Unknown, never
collapse unreadable metadata to Absent. A hashed target name is checked against full context on
positive reads; no decoded foreign group can redirect its classification onto another target.
Construction need not expand every SDK/source body merely to preserve this negative inventory.

Paths derive solely from the original Store and closed layout enums: namespace root, per-source
key from bounded group+full signer, small intent, exact seed/source/head slots and immutable page
IDs. No peer/caller filename, URL, server alias or public BlobStore namespace is involved.
Actual inner full context is checked as well as any hashed filename. Directory/file replacement
and symlink assumptions must match the supported live-vault session model; identity/path checks
are not advertised as a hostile-filesystem or exclusive-link guarantee they do not provide.

Any known/unknown V2 source for a target reserves that key negatively for old v1 callers. Check
BOTH source namespaces before old absent-head/unexposed or numeric snapshot paths can infer
absence. Include explicit protocol kind in runtime/pin source classification; raw OwnerFactId
or existence of an empty v1 head is insufficient. Cross-format writers cannot cancel/rebind
each other's original scope. The stronger fence must not block independently admitted other
groups merely because an unrelated JOIN/catalog write has retained debt.

## Exact original bootstrap container

Prepare one bounded, independently tagged/key-separated sealed bootstrap container ONCE. Its
complete frame ID includes the original nonce. It binds original vault/group/full signer/Profile,
creation attempt and planned scope lineage, exact public genesis/header IDs, Profile-bound S0
digest and limits, COMPLETE original private S0, and COMPLETE original encrypted record/manifest
frames from the actual source owner. The exact grammar and maximum need their own codec review.
It is separately paid private source custody, not the archive's512KiB public-candidate journal.

This self-contained container can supply exact repair bytes without reconstructing a device,
sampling another SDK group, creating a Fresh proof or resealing public pages. Keep a complete
immutable seed before writing the canonical source. Short writes to that source can be completed
only from the complete independently authenticated seed (or same warm original), through the
same validated object/parent and exact-prefix comparison. Unknown/non-prefix/replaced sources
remain held. The first seed's own partial failure cannot authorize repair or a positive source.

Before a covering head references the genesis manifest, also write/sync the ORIGINAL record and
manifest ciphertext as separate immutable pages. Historical page access must not depend on the
bootstrap container's SDK bytes. It may serve as the current private SDK source later, but can
be reclaimed only when no Current/pending/retry obligation references it and independent public
pages are durable. This prevents immutable history retaining every superseded private snapshot.

Final save admission is original creation/scope plan -> unified head -> synchronous Store I/O.
Recheck original negatives AFTER waiting for each writer. Required file and parent barriers
precede the opaque SavedUnexposed result. Failure retains the same container, pages, nonce and
fee in the original owner/runtime debt cell; a caller drop cannot let a new writer overtake it.
Do not keep a Store/key/session or transport in detached network work. This slice has no network.

## Grants, memory and cold reads

An original persistent user-creation grant, identified before SDK work, pays its actual attempts.
Restart, another mount, a new local activation or a failed seed write cannot reset it. Distinguish
a proved unexposed failed attempt from an ambiguous admitted source. A source that may exist is
looked up/repaired by its original grant; it cannot be replaced by another freshly generated group.
The concrete grant/source transition is required implementation, not a counter parsed as a fee.

Enumerate and actually reserve before each phase: input/live SDK/provider/backing, cached S0,
public founder and genesis preparation, compound plaintext/cipher/frame, exact retained source
and seed, read/unframe/plain overlaps, file identities/handles, head/intent and persistent bytes.
The configured limits are trusted policy, not physical free-space reservation or an RSS claim.
Existing founder64KiB, public-package512KiB, ReplayMath1MiB and JOIN16MiB allowances are distinct.
Do not silently borrow any of them for this private SDK/source container.

Cold inspection returns paid bounded OFFLINE DATA with explicit completeness. It verifies the
actual selected files/frame IDs/contexts, public genesis/state/signatures and original snapshot
digest. It does not expand arbitrary JSON/OpenMLS groups, recreate Fresh or return a runnable
Server. Actual typed SDK restore/admission and Active host memory remain later gates before
Current. There is no generic decrypted page/provider native command.

## First executable evidence required later

cached SDK S0 and real encrypted pages. Assert no scope row exists during any pre-source failure.
Inject failure before/after small intent, first seed, short writes, child sync, source rename,

Race old issuance, v1 absent-source recovery, target replacement, mount/lock and same-label new

Reopen through the real mandatory namespace and read exact public originals offline, proving it
grants no Current/Fresh/Ready. Compiler/tests/builds remain paused; none of this evidence exists yet.
