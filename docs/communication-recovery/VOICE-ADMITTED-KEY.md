# Admitted-call activation and original key publication

V2 remains off in the App. This work connects fixed admitted-profile native
commands to the actual original Actor and Root. It does not complete bilateral
admission, Ready, SDP/ICE/RTC, member media relay or physical call acceptance.

The new commands prepare an `AdmittedCall` candidate, retain one paid original
activation, select its exact Root residence, and commit native activation under
the original UI-session guard. Existing-profile commands cannot activate that
candidate or adopt its grant. An accepted activation is historical metadata;
every later positive effect independently checks the current original owner.

Key admission delegates one browser computation to one native owner/executor.
Publication freezes its original join and validated uncompressed P-256 point.
The separately paid native task owns publication through the actual Root outcome,
Actor argument retirement and final native check. The UI guard travels with that
task, rather than an observing invoke. Lock registration is checked again inside
Coordinator; a stale successful Root receipt can record historical publication
but cannot return current publication permission.

Uncertainty is not rejection. A lost callback retains the original task, key,
payment and arguments. Negative recovery requires the exact outside-Box task
return and actual original Root residence return. It cannot regenerate the key,
refund an ambiguous attempt, replace the selected call or manufacture Ready.
Accepted and rejected terminal replies remain in the original paid native cell
until explicit acknowledgement. Collection additionally requires actual task
return and SDK settlement. A bounded maintenance pass revisits acknowledged
active calls after normal End, so an early acknowledgement cannot strand the
32-record activation index.

The public reply distinguishes actual historical publication, known refusal,
unknown work that closed after actual Root return, and an exact closed generation
whose publication never started. Tags come from typed native facts, never error
Strings. A missing row provides no proof. Browser cleanup acknowledges a known
terminal result before settling its SDK registration; that registration keeps the
same cell available if the acknowledgement reply is lost. Never-started closure
requires no terminal acknowledgement because no publication cell was created.

Admitted presence uses the existing authenticated announcement/proof wire
grammar, independently funded and bound to the selected residence. Its watcher
can discover peers while rejecting legacy endpoint/source access to that call.
An announcement or proof alone says nothing about admitted protocol support,
capacity, a committed bilateral round, Ready or media permission.

  18 KiB; its fee is now 19 KiB, with the full compiled guard retained.
- Native publication: 9,564 bytes exceeded 8 KiB; its independent fee is now

  1 KiB fee rises to 1.5 KiB with the complete guard retained.
- The shared native key index has a separate 64 KiB process backing payment for
  both profiles, retained through empty capacity and actual table deallocation.

The group/process ceilings have not changed. These fees cover distinct owners;
no SDK completion, Actor retirement or Root return substitutes for another.
