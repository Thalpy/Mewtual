State vocabulary:

- **Not implemented**: the production path does not exist.
- **Implemented, unreviewed**: code exists, but the required independent verdict is absent or
  requested changes remain.
- **Reviewed, not integrated**: the bounded checkpoint passed but is not present in the integrated
  revision.
- **Not executed**: no result exists for the named revision/environment.
- **Failed**: the command or CI job ran and did not pass. Environment/setup failures are recorded
  as failures, not product defects, until a configured run reproduces them.
